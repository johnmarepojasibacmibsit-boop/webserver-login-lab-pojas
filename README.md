## Installation Instructions
1. Install Apache HTTP Server.
2. Install PHP and configure Apache to use PHP.
3. Install PostgreSQL and pgAdmin.
4. Create the `lab_login` database.
5. Import the `sql/database.sql` file.
6. Place the project folder inside the Apache `htdocs` directory.
7. Open `http://localhost/login-system/public/` in your browser.
